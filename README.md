# Rock Paper Fists — Privacy Policy

The privacy policy page for the game Rock Paper Fists, served by GitHub Pages:
https://alienbb80.github.io/rock-paper-fists-privacy/

`index.html` is generated from the game's own policy text (`game/privacy.ts` → `node tools/gen-privacy.mjs` in the game repository), so the page and the in-game Settings › Privacy Policy always say the same thing. Don't edit it by hand: change the text in the game, regenerate, and copy the file here.
